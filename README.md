# GetDrive

Адаптивна сторінка підготовки до практичного іспиту з водіння у Львові.

## Форма зворотного зв'язку

Форма містить поля імені, електронної пошти, номера телефону, повідомлення та обов'язкову згоду з політикою конфіденційності.

Після успішної перевірки полів браузера відкривається доступне модальне вікно з підтвердженням надсилання. Вікно можна закрити кнопкою «Закрити», натисканням клавіші Escape або кліком на затемнений фон.

Проєкт використовує HTML5, Tailwind CSS через CDN та Vanilla JavaScript. Додаткові мінімальні стилі знаходяться в `assets/css/styles.css`, логіка модального вікна — в `assets/js/validation.js`.

## Запуск

Відкрийте `index.html` через Live Server або будь-який локальний HTTP-сервер у корені проєкту.
